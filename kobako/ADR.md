# ADR-001: 既存 Pages の小さな静的ゲームとして配信

2026-10-26 / Accepted (ローカル実装。公開未実施)

v3「小箱の約束」の問題と演出を再利用する。新しい Worker・API・プラットフォームは作らず、既存 Pages の明示的な許可リストに kobako を追加する。index.html 一つだけを配信し、開発文書・テストは除外する。既存9ルート・ルートページ・本ライオンの Worker は変更しない。

`legacy-routes.json` の `routes` は別 platform の9ルート契約と共有される。既存9件を維持し、小箱は `pagesOnlyRoutes` として Pages だけに追加する。Pages ビルドは9件と追加1件のID・重複・パスを検証する。platform の契約・テストを緩めない。

文字盤は JavaScript で生成せず HTML に置く。JavaScript はその文字盤を読んで操作を追加する。JS 無効・添付ビューアでのスクリプト遮断でも問題が空欄にならない。初期化成功前は操作 UI を隠し、文字を読みながら考えられる状態にする。ヒント・解答は閉じた details 内に置く。クライアント内の答えは秘密として保護しない。

メディアファイルの追加・変更なし。共有画像変換の対象はない。状態はページ内だけに保持し、再読込でリセット。任意の文字の消去／復元、undo、reset、動作軽減対応を維持する。
